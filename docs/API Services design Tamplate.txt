7. Folder Structure (Layered Scaffolding):
- Use a clean, layered architecture for each service.
- Example:
  └── affiliate-activity-service/
      ├── alembic/              # Alembic migration scripts
      ├── alembic.ini           # Alembic config file
      ├── controllers/          # Route handlers
      ├── services/             # Business logic
      ├── models/               # SQLAlchemy models
      ├── routes/               # Route declarations
      ├── jobs/                 # Background workers or cron logic
      ├── events/               # Redis/pub-sub listeners and emitters
      ├── utils/                # Shared helpers and validators
      ├── config/               # Service-specific config (e.g., TTLs, limits)
      ├── Dockerfile            # Container definition
      └── main.py               # Entry point for service registration

8. Alembic Migrations:
- Use Alembic for version-controlled schema evolution.
- Key commands:
  - `alembic init alembic` → Initialize migration folder
  - `alembic revision --autogenerate -m "init"` → Create migration
  - `alembic upgrade head` → Apply latest migration
- Store migration history in `alembic/versions/`
