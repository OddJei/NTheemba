Affiliate Pool Service (APS)

1. Description:
Manages the affiliate pool balance, performance metrics, and payout logic. Tracks monthly platform contributions, calculates weighted scores, applies multipliers (earned or paid), and triggers 6-month payouts. Sends weekly notifications to affiliates showing their holdings and promoting multiplier upgrades. Auto-assigns Gold tier to first-time affiliates for their first 6 months.

2. Features:
- Receive monthly pool contributions from RPS
- Track affiliate performance metrics:
  - sales_volume
  - unique_buyers
  - msme_referrals
  - conversion_quality
- Normalize metrics and apply weights:
  - Sales Volume → 50%
  - Unique Buyers → 20%
  - MSME Referrals → 20%
  - Conversion Quality → 10%
- Request multiplier from AMS (earned or paid)
- Calculate boosted score and payout share
- Trigger 6-month affiliate payouts
- Emit AffiliatePayoutRequested to RPS
- Send weekly notifications with:
  - Current score and estimated payout
  - Multiplier upsell CTA
- Auto-assign Gold multiplier to new affiliates (first 6 months)

3. Schema:
Table: affiliate_pool_service.affiliate_metrics
- id: UUID (PK)
- affiliate_id: UUID (FK → affiliate_service.affiliates.id)
- sales_volume: NUMERIC
- unique_buyers: INTEGER
- msme_referrals: INTEGER
- conversion_quality: NUMERIC
- tier: ENUM('bronze', 'silver', 'gold')
- last_updated: TIMESTAMP

Table: affiliate_pool_service.pool_balance
- id: UUID (PK)
- month: TEXT (e.g. '2025-10')
- amount: NUMERIC
- created_at: TIMESTAMP

Table: affiliate_pool_service.weekly_notifications
- id: UUID (PK)
- affiliate_id: UUID
- snapshot_data: JSONB
- sent_at: TIMESTAMP

Table: affiliate_pool_service.payout_history
- id: UUID (PK)
- affiliate_id: UUID
- payout_amount: NUMERIC
- boosted_score: NUMERIC
- multiplier_used: NUMERIC
- payout_period: TEXT (e.g. '2025-H2')
- created_at: TIMESTAMP

4. Routes:
POST   /pool/contribution                     → Add monthly pool contribution
POST   /metrics/update                        → Update affiliate metrics
GET    /metrics/{affiliate_id}                → Get metrics for an affiliate
GET    /pool/balance                          → Get current pool balance
POST   /pool/reset                            → Reset all metrics after payout
POST   /notify/weekly                         → Trigger weekly notification batch
POST   /payout/trigger                        → Trigger 6-month affiliate payout
GET    /payout/history/{affiliate_id}         → View past payouts

5. External Outreach:
- Receives pool contributions from RPS
- Requests multipliers from AMS
- Emits AffiliatePayoutRequested to RPS
- Sends weekly notifications via NotificationService
- Emits AffiliatePoolSnapshot to AnalyticsService

6. Background Work:
- Weekly notification scheduler
- Snapshot generator for affiliate holdings
- Multiplier upsell logic based on performance
- Auto-assign Gold tier to new affiliates
- Scheduled 6-month payout trigger
- Audit logs and payout history

10. Scalability Readiness:
- Current Target (1–500 affiliates):
  - Indexed metrics table
  - Manual pool snapshot and reset
  - Basic notification batch

- Ready for 1,000 affiliates:
  - Redis cache for leaderboard
  - Partitioned metrics table by affiliate_id
  - Async notification queue

- Path to 10,000+ affiliates:
  - Sharded metrics table by region
  - Event-driven notification engine
  - Read replicas for analytics
  - Autoscaling payout and notification jobs
  - Personalized upsell logic based on affiliate behavior
