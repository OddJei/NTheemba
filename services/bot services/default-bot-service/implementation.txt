## 🎯 **Key Implementation Logic**

The core routing logic will be:
```python
def route_to_handler(session_mode, user_role, node_name):
    if session_mode == "public":
        return f"handlers.public_mode.{node_name}"
    elif session_mode == "registered":
        if user_role == "msme":
            return f"handlers.registered_mode.msme.{node_name}"
        elif user_role == "affiliate":
            return f"handlers.registered_mode.affiliate.{node_name}"
```
